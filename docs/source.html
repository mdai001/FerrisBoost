Core modules

Each link opens the current public implementation on the default develop branch.

Public Rust APIsrc/lib.rs

Exports training configuration, data sources, binning strategies, callbacks, model types, and the top-level training entry point.

Training orchestrationsrc/train.rs

Coordinates setup, deterministic sampling, metric evaluation, early stopping, histogram construction, and CPU/GPU backend selection.

Read train.rs ↗
Histogram enginesrc/hist.rs

Builds and subtracts quantized histograms with deterministic accumulation behavior for the CPU reference path.

Read hist.rs ↗
Input sourcessrc/source/

Implements dense, Parquet, CSV, Arrow, parallel file-reader, and prediction input paths with schema validation and bounded materialization.

Browse source readers ↗
GPU memory plannersrc/gpu_mem_plan.rs

Chooses device residency and streaming plans from dataset shape, runtime memory observations, histogram needs, and safety margins.

Read gpu_mem_plan.rs ↗
CUDA backendsrc/backend/cuda/

Owns training contexts, compact selected-feature histograms, kernel launches, transfers, and optional GPU inference.

Browse CUDA backend ↗
Predictionsrc/inference.rs

Traverses immutable trees with deterministic row ordering and prepares compact inference-only feature representations.

Read inference.rs ↗
Models and interchangesrc/tree.rs

Defines nodes, trees, model metadata, save/load behavior, and the supported XGBoost JSON schema mirror.

Read tree.rs ↗
Python extensionsrc/python.rs

Exposes training and model operations through PyO3 while releasing the GIL around native training and prediction work.
